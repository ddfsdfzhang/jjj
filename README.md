# 棋间 · 五子棋

这是一个纯静态的五子棋网页，棋盘、规则和简单人机逻辑全部运行在浏览器中，不需要服务器、数据库或后端接口。

## 部署到 Cloudflare Pages

将此目录推送到 GitHub/GitLab 后，在 Cloudflare Dashboard 打开 Workers & Pages → Create application → Pages → Connect to Git。Framework preset 选 None，Build command 留空，Build output directory 使用项目根目录。也可以直接上传包含 index.html、styles.css、app.js 的文件夹。
